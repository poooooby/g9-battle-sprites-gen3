# assets/front

The DBK **front** (enemy) battle-sprite sheets ship in this folder — one PNG per
Pokemon, in the pack's animated format.

* File name = the pack's own stem, e.g. `ABOMASNOW.png`, `CHARIZARD_1.png`
  (mega Charizard X), `ALCREMIE_63.png` (gigantamax Alcremie),
  `ABOMASNOW_female.png`.
* One PNG per Pokemon: a horizontal frame strip. Do not split it -- the mod
  crops frames out in memory.
* Folder names are case-sensitive and lower-case here: `front`, `front_shiny`,
  `back`, `back_shiny`.

A species the pack has no sheet for simply uses the game's vanilla pic. The mod
does not touch the network, so sheets only ever come from these four folders.

The sprite art is community fan art (the EeveeExpo Resource Pack and La Base de
Sky's DBK pack) -- see [`../CREDITS.md`](../CREDITS.md) for the full artist
credits and [`../THIRD-PARTY-NOTICES.md`](../THIRD-PARTY-NOTICES.md) for the
licence notes.
